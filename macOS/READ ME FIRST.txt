Yakusuru (macOS)

1. Drag "Yakusuru.app" to your Applications folder, then open it from there
   (or simply double-click it right here).
   First run: it opens Terminal, finds a native Python (Apple Silicon: arm64 Python 3.10 to 3.14;
   Intel Macs: 3.10 to 3.12), sets up the app once, then opens it.
2. If setup ever breaks, double-click "Install or Repair.command" (or run it with --reset).

Intel/Rosetta Pythons are skipped on Apple Silicon. Get a native one from python.org
(universal2 installer) or an arm64 Homebrew in /opt/homebrew.
If macOS says the app can't be opened: right-click it, choose Open, then Open again.
